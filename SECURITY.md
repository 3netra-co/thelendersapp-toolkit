# Security policy

The Toolkit is pre-production and must not be used with confidential borrower,
lender, credential, or customer data.

Please report suspected vulnerabilities privately to
[support@thelenders.app](mailto:support@thelenders.app). Do not open a public
issue containing exploit details, secrets, personal information, or customer
data.

No deployment should retain a maintainer's cloud credentials. Customer runtime
resources, identities, data, secrets, and charges must remain in the customer's
cloud account unless a future hosted offering states otherwise explicitly.
